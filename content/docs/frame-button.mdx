FrameButton is a targeting reticle for your call to action. Four corner markers float just outside the edges. On hover they spread outward and brighten while a band of light sweeps across the face, and on press they snap in tight against the border, locking on. Keyboard focus gets the same hover treatment.

## Install

Add the item with the shadcn CLI.

<Cmd>@evilbuttons/frame-button</Cmd>

## Usage

### Button

```tsx
import { FrameButton } from "@/components/evil-buttons/frame-button";

export function ButtonDemo() {
  return <FrameButton>Get Started</FrameButton>;
}
```

### Link

```tsx
import { FrameButton } from "@/components/evil-buttons/frame-button";

export function ButtonDemo() {
  return (
    <FrameButton as="link" href="https://github.com/radiumcoders/evil-buttons">
      Star on GitHub
    </FrameButton>
  );
}
```

## Props

The component spreads native `button` props, or anchor props when `as="link"`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | - | The button content. |
| `variant` | `"default" \| "secondary" \| "outline"` | `"default"` | Visual style of the button. |
| `glow` | `boolean` | `false` | Blooms a soft glow behind the button on hover. |
| `size` | `number \| string` | `14` | Corner marker size in px, or a Tailwind size class like `"size-4"`. |
| `offset` | `number` | `6` | Distance in px the markers sit outside the button's edge. |
| `hoverOffset` | `number` | `5` | How far in px the markers spread on hover. |
| `as` | `"button" \| "link"` | `"button"` | Renders a button or a Next.js `Link`. |
| `href` | `Route \| UrlObject` | - | Link destination when `as="link"`. |
| `className` | `string` | - | Extra classes passed to the root element. |

## Notes

- `FrameMarkers` is exported on its own. Drop it inside any `motion` element that sets `rest`, `hover`, and `tap` variants to give it the same brackets.
- The markers are two-sided borders rather than icons, so they stay crisp at any size.
- The `default` variant is the graded dark surface with the hairline ring shared by MinimalButton and CommandButton, keeping its square corners so the brackets line up. Every variant uses the same spring press.

## Registry

The registry item includes `components/evil-buttons/frame-button.tsx` and installs `motion`, `clsx`, and `tailwind-merge` as dependencies. The component imports `cn` from `@/lib/utils`, matching the project alias in `components.json`.
