AshBurstButton is the darker twin of ConfettiButton. It looks like a calm, ringed dark button with a small flame icon. Click it and the face glows like an ember while charcoal ash and a few sparks erupt, then Matter.js gravity makes them bounce off the button and pile onto its top edge.

## Install

Add the item with the shadcn CLI.

<Cmd>@evilbuttons/ash-burst-button</Cmd>

## Usage

```tsx
import { AshBurstButton } from "@/components/evil-buttons/ash-burst-button";

export function ButtonDemo() {
  return (
    <AshBurstButton
      colors={["#171717", "#404040", "#737373", "#f97316"]}
      particleCount={120}
      onDestroy={() => console.log("Burned.")}
    >
      Incinerate
    </AshBurstButton>
  );
}
```

## Props

The component spreads native `button` props. `onClick` still fires before the burst; call `event.preventDefault()` to skip it.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | - | Button label. Falls back to `label`. |
| `label` | `React.ReactNode` | `"Delete"` | Label used when no children are provided. |
| `particleCount` | `number` | `80` | Physics particles per burst. |
| `spread` | `number` | `110` | Explosion spread in degrees. |
| `startVelocity` | `number` | `42` | Launch velocity (mapped into Matter). |
| `colors` | `string[]` | charcoal/ember palette | Custom particle colors. Warm reds and oranges get a soft glow. |
| `icon` | `boolean` | `true` | Show the leading flame icon. |
| `onDestroy` | `() => void` | - | Fired after each ash burst. |
| `className` | `string` | - | Extra classes merged onto the button. |

## Notes

- Shares the graded dark surface, hairline ring, and spring press used by MinimalButton and CommandButton.
- Each click adds a short ember glow to the button and spawns Matter.js bodies on a full-viewport overlay canvas. The button itself is a live static collider (synced every frame), so ash bounces off the sides and settles on top.
- Physics is skipped when the user prefers reduced motion.

## Registry

The registry item includes `components/evil-buttons/ash-burst-button.tsx`, and adds `matter-js`, `clsx`, and `tailwind-merge` as dependencies.
