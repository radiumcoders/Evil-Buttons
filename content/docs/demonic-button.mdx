DemonicButton is a hold-to-summon ritual. Press and hold and a pair of shaded, ridged horns slowly push up from behind the button while it trembles and an ember glow rises inside it. Flames build from a flicker into a full blaze, and once the charge completes the demon is summoned. Let go and everything sinks back into the dark.

<Cmd>@evilbuttons/demonic-button</Cmd>

## Usage

```tsx
import { DemonicButton } from "@/components/evil-buttons/demonic-button";

export function ButtonDemo() {
  return (
    <DemonicButton holdDuration={1800} onSummon={() => console.log("Summoned")}>
      Corrupt the World
    </DemonicButton>
  );
}
```

## Props

The component spreads native `button` props except `onClick`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | - | Button label. Falls back to `label`. |
| `label` | `React.ReactNode` | `"Summon"` | Label used when no children are provided. |
| `holdDuration` | `number` | `2200` | Milliseconds of holding needed to fully summon. |
| `onSummon` | `() => void` | - | Fired once each time the charge reaches 100%. |
| `className` | `string` | - | Extra classes passed to the button. |

## Notes

- Fire is a small canvas particle system: soft sprites are pre-rendered along a white-hot to red to smoke color ramp, then pushed up by buoyancy, pulled toward the centerline, and swayed by turbulence.
- The horns are inline SVG with a keratin gradient, side shading, and growth ridges, rising and untilting from behind the button as the charge builds.
- One `requestAnimationFrame` loop drives the charge, horns, glow, and fire by writing styles directly, so React does not re-render every frame. The loop stops once everything has settled.
- Releasing drains the charge faster than it fills. Hold with the pointer, <kbd>Space</kbd>, or <kbd>Enter</kbd>.
- With reduced motion enabled, the trembling and flames are skipped; the horns and glow still follow the charge.
- `data-state` is `summoned` at full charge and `idle` otherwise.
- Shares the graded dark surface, hairline ring, and spring press used by MinimalButton and CommandButton. The button stays pressed while held and exposes `data-holding` during the hold.
