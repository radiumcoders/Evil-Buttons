RealisticSwitch is a rocker switch built in CSS 3D. A rounded housing with real depth sits at a three-quarter angle on a soft floor shadow and leans gently toward your pointer. The housing is ceramic white in light mode and graphite in dark mode. Press it and it rocks to center, then snaps over. The pushed-in half sinks into shadow, the other half tilts up into the light, and when it is on the rocker lights up from inside and tints the surface around it. It is a native `role="switch"` button, so clicks, Enter, and Space all work.

## Usage

```tsx
import { RealisticSwitch } from "@/components/evil-buttons/realistic-switch";

export function PowerSwitch() {
  return (
    <RealisticSwitch
      sound
      aria-label="Main power"
      onCheckedChange={(on) => console.log("power:", on)}
    />
  );
}
```

Controlled usage:

```tsx
<RealisticSwitch checked={isLive} onCheckedChange={setIsLive} color="#1f6feb" />
```

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `checked` | `boolean` | - | Controlled on state. |
| `defaultChecked` | `boolean` | `false` | Initial state when uncontrolled. |
| `onCheckedChange` | `(checked: boolean) => void` | - | Called when the switch flips. |
| `color` | `string` | `"#e1261c"` | Rocker color. Any CSS color. |
| `markColor` | `string` | white | Color of the printed O and I marks. |
| `tone` | `"auto" \| "light" \| "dark"` | `"auto"` | Housing finish: follow the theme, or force ceramic white or graphite. |
| `illuminated` | `boolean` | `true` | Light the rocker from inside while it is on. |
| `sound` | `boolean` | `false` | Play a short mechanical click when it flips. |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Scales the whole switch. |
| `disabled` | `boolean` | `false` | Disables the switch. |
| `aria-label` | `string` | `"Power"` | Accessible name for the switch. |
| `className` | `string` | - | Extra classes on the button. |

## Notes

- On means the I half is pushed in, so the O half rises toward you, just like a real rocker.
- The click sound is synthesized with the Web Audio API, so there are no audio files to ship. It stays silent where audio is unavailable.
- Everything is sized in `em`, so `size` just sets the font size the whole switch scales from.
- The snap and the pointer lean are skipped when the user prefers reduced motion, and the lean only follows a mouse, not touch.

## Registry

The registry item includes `components/evil-buttons/realistic-switch.tsx` and installs `motion`, `clsx`, and `tailwind-merge` as dependencies. The component imports `cn` from `@/lib/utils`.
