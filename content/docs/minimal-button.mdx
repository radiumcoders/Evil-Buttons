## Props

The component spreads native `button` props and forwards its ref to the button.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | - | The button label. |
| `arrow` | `boolean` | `true` | Show a trailing chevron that nudges forward on hover. |
| `className` | `string` | - | Extra classes passed to the button. |

## Good to know

- One layered `box-shadow`, no wrapper elements.
- Stays dark in both themes.
