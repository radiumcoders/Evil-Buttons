PillButton is a compact two-state pill switch. Click it and the pill springs from a muted off face to an on face whose status light blinks on. Hover it and the label rolls through letter by letter. The faces follow your theme's `muted` and `primary` colors by default, and the pill sizes itself to its longer label.

## Install

Add the item with the shadcn CLI.

<Cmd>@evilbuttons/pill-button</Cmd>

## Usage

```tsx
import { PillButton } from "@/components/evil-buttons/pill-button";

export function ButtonDemo() {
  return (
    <PillButton
      primaryLabel="Off"
      secondaryLabel="On"
      onOpenChange={(open) => console.log("open:", open)}
    />
  );
}
```

Controlled usage:

```tsx
<PillButton
  primaryLabel="Mute"
  secondaryLabel="Live"
  isOpen={isLive}
  onOpenChange={setIsLive}
/>
```

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `primaryLabel` | `string` | - | Label shown on the closed face. |
| `secondaryLabel` | `string` | - | Label shown on the open face. |
| `primaryClassName` | `string` | `bg-muted text-muted-foreground` | Classes merged onto the off face. |
| `secondaryClassName` | `string` | `bg-primary text-primary-foreground` | Classes merged onto the on face. |
| `isOpen` | `boolean` | - | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Initial open state when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | - | Called when the toggle state changes. |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Pill height and text size. |
| `disabled` | `boolean` | `false` | Disables the switch. |
| `className` | `string` | - | Extra classes on the outer pill container. |
| `ariaLabel` | `string \| ((isOpen: boolean) => string)` | label of active face | Accessible name for the switch. |

## Notes

- The outer element is a native `<button role="switch">` with `aria-checked`, so Enter, Space, focus rings, and `disabled` work out of the box. The hidden face is `aria-hidden`.
- `PillFace` and `RollingLabel` are also exported if you want to reuse the status light or the letter-by-letter roll elsewhere. `RollingLabel` takes a `stagger` in seconds.
- The face change is a spring, and the pill presses down slightly under the pointer.

## Registry

The registry item includes `components/evil-buttons/pill-button.tsx` and installs `motion`, `clsx`, and `tailwind-merge` as dependencies. The component imports `cn` from `@/lib/utils`.
