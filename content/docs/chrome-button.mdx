ChromeButton is a pill set in a machined bezel with a layer of liquid chrome sweeping across its face: bright white chrome over black, or dark chrome over white. Hover it and the chrome ripples around your cursor while the sweep speeds up; press it and a ring pushes out from where you clicked. The label inverts over every band that passes under it.

## Install

Add the item with the shadcn CLI.

<Cmd>@evilbuttons/chrome-button</Cmd>

## Usage

```tsx
import { ChromeButton } from "@/components/evil-buttons/chrome-button";

export function ButtonDemo() {
  return (
    <ChromeButton tone="light" speed={1.4} onClick={() => console.log("Polished.")}>
      Chrome
    </ChromeButton>
  );
}
```

## Props

The component spreads native `button` props and forwards its ref.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | - | Button label. Falls back to `label`. |
| `label` | `React.ReactNode` | `"Chromy"` | Label used when no children are provided. |
| `tone` | `"dark" \| "light"` | `"dark"` | White chrome sweeping over black, or dark chrome sweeping over white. |
| `speed` | `number` | `1` | Speed multiplier for the chrome sweep. |
| `interactive` | `boolean` | `true` | Ripple the chrome around the pointer and on press. |
| `className` | `string` | - | Extra classes merged onto the bezel. |

## Notes

- Self-contained: the shader is plain WebGL in the component file, with no `ogl` or external registry dependency.
- The chrome only animates while the button is on screen and the tab is visible. The plain black or white face shows until the first frame paints, and stays if WebGL is unavailable.
- Keyboard presses ripple from the center.
- The label is white with `mix-blend-difference`, so it flips to dark wherever a bright band passes and back again, on both tones.
- With reduced motion, the chrome renders as a still frame: no sweep or ripple.

## Registry

The registry item includes `components/evil-buttons/chrome-button.tsx`, and adds `clsx` and `tailwind-merge` as dependencies.
