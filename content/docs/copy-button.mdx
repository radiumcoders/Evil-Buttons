---
title: CopyButton
description: A copy button that floats the copied text up off itself, so you see exactly what landed on the clipboard.
category: Utility
---

CopyButton writes a string to the clipboard and shows you what it copied. On success, a small chip with the copied text lifts off the top of the button and fades away while the clipboard icon springs into a check. If the write fails, the button says so and turns destructive. After `timeout` it settles back to idle.

<Cmd>@evilbuttons/copy-button</Cmd>

## Usage

```tsx
import { CopyButton } from "@/components/evil-buttons/copy-button";

export function ButtonDemo() {
  return (
    <CopyButton
      value="npm install evil-buttons"
      onCopy={(text) => console.log("Copied", text)}
    />
  );
}
```

## Props

The component spreads native `button` props except `value` and `onCopy`, and forwards its ref to the button.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | Text written to the clipboard. Required. |
| `timeout` | `number` | `1500` | Milliseconds before the button returns to idle. |
| `copyLabel` | `React.ReactNode` | `"Copy"` | Label shown before copying. |
| `copiedLabel` | `React.ReactNode` | `"Copied"` | Label shown after a successful copy. |
| `errorLabel` | `React.ReactNode` | `"Copy failed"` | Label shown when the clipboard write fails. |
| `showValue` | `boolean` | `true` | Float a chip with the copied text up off the button. |
| `onCopy` | `(value: string) => void` | - | Fired with the copied text after a successful write. |
| `className` | `string` | - | Extra classes passed to the button. |

## Notes

- Uses `navigator.clipboard.writeText` on secure pages and falls back to a hidden textarea with `document.execCommand("copy")` elsewhere, so it also works over plain HTTP.
- Each successful copy launches its own chip, so rapid copies stack instead of cutting each other off.
- Invisible copies of every label reserve the widest one, so the button never changes width between states.
- A visually hidden status region announces "Copied to clipboard" or "Copy failed" to screen readers.
- `prefers-reduced-motion` skips the floating chip; the icon and label still change.
